# Qualitative blend comparison (for the Figma results figure)

Kept **local** (not in the paper) per 2026-08-23 decision: the paper's qualitative exhibit will be a
hand-made colorful Figma figure (like TwistBench), built from this material. Data from the Kombine v1
run (`data/kg_creat/kombine_v1/`, temp 0.9, 7 models). Each model's ONE blend of a shared pair, with
its generic space and top emergent statements.

**The gradient to convey:** stronger models (gpt-5, claude, gemini) read off *specific* emergent
structure neither input carries (co-composition of reality, provinces "placed on hold", musicians as
living deities); weaker models (qwen, gpt-4o-mini, llama-8b) emit generic restatements true of almost
any combination ("spontaneously re-created", "open to multiple interpretations", "a dialogue between
past and present"). Jazz + Mythology is the cleanest single exhibit; telephone + Roman Empire is the
wittiest (gpt-5 "borders track signal coverage"; claude "provinces can be placed on hold").
