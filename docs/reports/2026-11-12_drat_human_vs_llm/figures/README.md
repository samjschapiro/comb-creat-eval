# Figures: DRAT human study and human-vs-LLM battery

Copies of the latest version of each figure. The originals stay in their run directories (listed below), which also hold the config and numbers behind each figure. Earlier runs on the 2026-10-27 export and the 2026-11-04 SCTT run are superseded and not copied here.

Humans: 240 analysed participants from the 2026-11-10 export (Stony Brook, IRB2026-00448). LLMs: 40 models from the human-battery run of 2026-11-10. No figure adjusts for response length.
