# plot_twist — experiment scaffolds

Setups for the two hypotheses logged in [HYPOTHESES.md](../../HYPOTHESES.md):
**H4** (embedding semantic-distance metrics are blind to transformational
creativity) and **H5** (human plot twists beat LLM plot twists, gap in
coherence). Status: scaffold only — no code yet (track Phase 0). Both reuse the
fixed-rubric judge (§3 of [paper_outline.md](paper_outline.md)) and the dat_eval
correlation pipeline.

Planned layout (mirrors other tracks):
```
src/plot_twist/
  dsi.py            # DSI scorer (BERT pairwise semantic distance over a narrative)
  rubric_judge.py   # fixed-rubric LLM-as-judge (surprise / coherence / prose / overall)
  structural.py     # T_mod x preservation from an extracted story DAG
  scripts/
    run_exp1_dsi.py        # H4: DSI vs rubric/human/structural on the twist sets
    run_exp2_human_llm.py  # H5: human vs LLM twists under the rubric judge
configs/plot_twist/
  exp1_dsi.yaml
  exp2_human_llm.yaml
data/plot_twist/           # gitignored: stimuli, generations, scores
  contrast_triples/        # twist / predictable / random  (shared with §3)
  human_twists/            # famous public-domain + WritingPrompts twist-tagged
  generations/<model>/     # LLM twists (matched prompts)
```

## Experiment 1 — DSI is blind to transformational creativity (H4)

**Goal.** Show DSI predicts *neither* the presence *nor* the quality of a plot
twist, while (a) still predicting general creative-writing quality on the same
stories and (b) being beaten by the structural metric — a double dissociation.

**Stimuli (three item sets).**
1. **Contrast triples** (shared with the benchmark): one setup → {twist /
   predictable / random} ending. Gives a *presence* label (twist vs not) and a
   coarse quality ordering. Target n ≥ 150 triples.
2. **Human-rated twist set:** stories with continuous human twist-quality ratings
   (the §3 validation subset). Gives a *quality* target.
3. **General creative-writing set** with human creativity ratings (e.g. the corpus
   DSI was validated on, or a creative-writing-rated slice) — the dissociation
   control, to confirm DSI *works* where it should.

**Conditions / metrics computed per story.**
- `DSI` — mean pairwise BERT cosine distance over content words (`src/plot_twist/dsi.py`;
  follow the original method). The metric under test.
- `rubric` — fixed-rubric judge surprise/coherence/overall (`rubric_judge.py`).
- `structural` — `T_mod x preservation` from the extracted DAG (`structural.py`).
- baselines: output length, a generic LLM story-quality rating.

**Procedure.**
1. Score every story in all three sets with DSI, rubric, structural, baselines.
2. **Presence:** logistic regression / AUC for `DSI -> twist-present?` on the triples
   (twist vs predictable). Repeat for structural and rubric.
3. **Quality:** Pearson/Spearman of `DSI` vs human twist-quality (set 2) and vs the
   rubric. Repeat for structural.
4. **Dissociation control:** Pearson of `DSI` vs human creativity rating on set 3
   (expect it to replicate DSI's validated positive correlation).

**Analysis / expected results (H4 predictions).**
- DSI presence AUC ≈ chance (0.45–0.58); DSI–twist-quality |r| < 0.15 n.s.
- DSI–general-creativity r ≳ 0.30 (control holds → null is twist-specific).
- Structural metric: presence AUC ≥ 0.75, quality r ≥ 0.40 (positive contrast).
- Report effect sizes + bootstrap CIs (small n; not p<.05 gating). A
  metric × task heatmap (presence / twist-quality / general-quality) is the figure.

**Confounds to control.**
- *DSI implementation drift* — validate `dsi.py` reproduces published DSI on a
  reference set before trusting the null (a null from a buggy DSI proves nothing).
- *Length* — DSI can scale with text length; length-match or covary.
- *Same-judge circularity* — don't let the rubric judge define both the quality
  target and the structural metric's validation; use the human ratings as the anchor.

## Experiment 2 — Human vs LLM twists (H5)

**Goal.** Show human twists out-score frontier-LLM twists under the fixed-rubric
judge, the gap is largest in **coherence**, it survives a **prose-quality
control**, and it holds in a **matched-prompt** head-to-head.

**Corpora.**
- **Human (famous):** public-domain short stories with canonical twists (e.g.
  Maupassant, Saki, O. Henry, Bierce; Cortázar where rights allow / paraphrase). The
  *ceiling* condition. Note survivorship + contamination explicitly.
- **Human (non-famous):** WritingPrompts twist-tagged stories — fairer, less famous.
- **LLM:** twists generated by the ≈31-model pool. Two prompt regimes:
  (i) free generation; (ii) **matched-prompt** — same WritingPrompts seeds the
  non-famous humans wrote to (controls prompt, genre, length, contamination).

**Scoring.**
- Fixed-rubric judge, **blind to authorship**, on dimensions: surprise,
  coherence, **prose quality** (added as a covariate), overall.
- Length/fluency-matched where possible; randomized order; multiple judge models for
  robustness (report inter-judge agreement).

**Procedure.**
1. Score all human + LLM twists with the blind rubric judge.
2. **Ceiling comparison:** famous-human vs LLM, per dimension.
3. **Matched-prompt comparison:** non-famous-human vs LLM on shared prompts.
4. **Prose control:** regress overall (and twist dimensions) on author-type with
   prose-quality as covariate; test whether the twist-dimension gap survives.
5. **Locus analysis:** compare the human–LLM gap on coherence vs surprise.

**Analysis / expected results (H5 predictions).**
- Famous-human > LLM overall (Δ ≥ 0.5) and on both surprise and coherence.
- Gap larger on **coherence** than surprise.
- Twist-dimension gap **survives** the prose covariate.
- Matched-prompt: human > LLM, smaller margin than famous.
- Bradley–Terry / mixed-effects model (story and judge as random effects); bootstrap CIs.

**Confounds to control.**
- *Contamination / familiarity* — judge may favor famous text → the matched-prompt
  + non-famous arms are the load-bearing comparison; report famous as an upper bound.
- *Prose confound* — the prose-quality covariate is mandatory, else "humans win"
  reduces to "humans write better prose," not "better twists."
- *Selection / survivorship* — famous = best-of-human; state it; the matched-prompt
  arm gives the average-vs-average estimate.
- *Judge bias* — multiple judges + human spot-check on a subset (ties to the §3
  judge-reliability analysis).
